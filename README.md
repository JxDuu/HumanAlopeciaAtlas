# HumanAlopeciaAtlas

This repository contains scripts used in the analysis of the manuscript: "**Distinct microenvironmental remodeling converges on impaired dermal regenerative signaling in human alopecia**".

## Data availability

AGA data (Wei et al.): [CNP0006019](https://db.cngb.org/cnsa/)

AA data (Ober-Reynolds et al.): [GSE212450](https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE212450)
